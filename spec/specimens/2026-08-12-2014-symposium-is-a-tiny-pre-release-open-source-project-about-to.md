# Symposium is a tiny pre-release open-source project about to catch or miss a wav

## Question
Symposium is a tiny pre-release open-source project about to catch or miss a wave. What is the single highest-leverage move, in what order do the candidate moves rank, and what genuine public good can this project realistically do? Also: tell us what we are wrong about.

Symposium (AGPL server, CC0 ledger format) is a multi-model deliberation MCP server: one tool, convene_council, fans a question out to Claude/GPT/Gemini/Grok/DeepSeek, preserves disagreement VERBATIM in a DISSENT section with per-advisor verdicts, synthesizes (or at high stakes refuses to conclude and returns open questions for the human), and writes every deliberation to a plain-Markdown ledger the human owns (schema symposium-ledger/v2). Principles: disagreement surfaced never averaged; cost visible before spent; the human is primary.

New design about to be built ("v0.7 retained seats"): council seats held by subscription-authenticated official CLIs (claude -p, codex exec, gemini) at zero marginal cost. These seats carry their human's context (CLAUDE.md, memory, config) — they are "retained counsel" representing their human, vs cold API seats as "neutral experts." Seat provenance (retained vs neutral) would be marked in the ledger schema, because a person's own AI is the least neutral juror they can seat (advocacy vs sycophancy).

Landscape (August 2026): personal agents exploded (OpenClaw: 200k+ GitHub stars, creator hired by OpenAI Feb 2026, now an independent open foundation; ClawHub has 5,705 community skills of which 341 were found malicious and 7.1% mishandle secrets — a trust crisis). Subscription auth went official (every major provider ships a subscription-authenticated scriptable CLI). Protocol stack: MCP won (97M monthly SDK downloads, all providers native); A2A (Linux Foundation) covers agent-to-agent comms; OSI spec (Jan 2026) covers semantic consistency. NO standard exists for deliberation records — how multi-agent disagreement is preserved, attributed, and returned to humans.

Candidate moves, all cheap for a solo project: (a) extract the CC0 ledger format into a standalone spec positioned as THE deliberation-record format, with real specimen ledgers; (b) ship an OpenClaw skill so any lobster can convene a council or sit as its human's retained advocate; (c) ship v0.7 retained seats + npm one-line install; (d) write the essay ("your AI represents you — who checks it?") with a real ledger as the centerpiece. The project is one person plus AI, pre-release, no audience yet. "Do a good" matters to the operator as much as adoption: norm-setting (dissent preserved verbatim, human primacy, provenance disclosure) while agent-era norms are wet cement.

- Uncertainties: whether a solo pre-release project's spec can get enough citation velocity to become a focal point before a well-funded competitor (OpenClaw foundation, or a provider) ships something similar under a bigger name; whether 'retained vs neutral seat' framing will resonate as a real trust primitive or read as a niche concern nobody outside this project cares about; how much the specimen ledgers need to be genuinely impressive/surprising (real disagreement, not staged) to carry the essay — this is doable but not guaranteed on first attempts

Shipping (b) first, badly, then fixing it in public, might generate more real-world pressure-testing of the provenance idea than a clean spec written in isolation.

The sequencing is c→a→d→b. Build the feature, make its records portable and inspectable, use a genuine ledger to tell the story, then enter the highest-risk distribution ecosystem. The realistic public good is modest but meaningful: establish a reusable audit trail for consequential AI-mediated decisions, where disagreement is not erased, advocates are labeled as advocates, uncertainty survives synthesis, and a human can inspect or export the basis for a recommendation. What you are wrong about: “zero marginal cost” is economically misleading. Subscription seats consume quotas, introduce account/ToS and automation fragility, and externalize opportunity cost to the subscriber. More importantly, retained context is not simply advocacy versus sycophancy: it may be uniquely informed counsel. Verbatim preservation also has privacy, prompt-injection, copyright, and sensitive-data consequences; immutable-looking ledgers need redaction, retention, and access controls.

*Dissent from framing:* The choice should not be framed as product versus standard versus essay. The unit of leverage is a credible public artifact: one working retained-seat deliberation accompanied by a portable, privacy-aware ledger and a clear argument. Also, “THE” standard is not a launch position a solo project can declare; earn it through adoption, compatibility, and governance.
- Uncertainties: Whether official subscription CLIs permit reliable noninteractive orchestration and redistribution-compatible use across providers.; Whether the early adopter wave is primarily OpenClaw users, MCP developers, or teams seeking governance/auditability.; Whether users will value a standalone deliberation-record standard before interoperability partners adopt it.; How much sensitive context retained CLIs expose when their outputs are persisted in a durable ledger.
- Self-objection: The ledger format, not retained seats, may be the true wedge: protocols win through early neutral standardization, while provider-specific CLI orchestration is brittle, legally contingent, and easy for incumbents to replicate. If so, spending first on v0.7 risks building a transient integration instead of owning the enduring category language.

## Synthesis
The synthesis adopts Claude’s core position as the spine: the single highest-leverage move is to treat (a) and (d) as one simultaneous motion—extract the CC0 ledger format now with 3–5 real specimen ledgers (including an eat-your-own-cooking deliberation on Symposium’s roadmap) and publish the essay centered on a real ledger into the existing OpenClaw/ClawHub trust-crisis conversation. Rank thereafter (c) then (b): retained seats next because they are cheap and generate more authentic specimens at scale; OpenClaw skill last, only after the skill carries a citable norm and hardened boundaries, given the malicious-skill and secrets-mishandling rates.

It adopts Grok’s emphasis that narrative and de-facto standards capture move faster than code in the 2026 attention economy, and that the essay is how the ledger format becomes known—but rejects Grok’s pure (d) >> (a) split and the placement of (b) above (c), because a specimen-backed CC0 spec is what makes the essay more than a blog post and because entering ClawHub without that payload is reputational downside, not distribution upside.

It rejects GPT’s c→a→d→b sequencing as first move. For a solo pre-release project with no audience, shipping retained-seat orchestration before a portable, citable record format and argument optimizes for a brittle integration that incumbents can replicate, rather than for the missing category language (deliberation records) that no OSI/MCP/A2A layer currently covers. Code does not spread itself here; a norm can be cited by people who never install the server. GPT’s own strongest self-objection (ledger-as-wedge) is decisive against GPT’s own ranking.

It partially adopts GPT on substance that must correct the operator’s framing: “zero marginal cost” is misleading (quotas, ToS, automation fragility, opportunity cost); retained seats are not inherently inferior jurors—they can be uniquely informed counsel—so provenance should disclose context and incentives without a built-in stigma; verbatim ledgers require redaction, retention, and access controls for privacy, injection, copyright, and sensitive data; and a solo project cannot declare itself “THE” standard—it can only publish a clean CC0 artifact and earn focal-point status. It fully adopts Claude’s dissent on framing: optimize for norm success (verbatim dissent preserved, provenance disclosed, human primacy) even if the project is later absorbed without attribution; project “catch the wave” survival is the less important, possibly sacrificial variable.

Genuine public good that is realistic: a citable, CC0, specimen-backed deliberation-record practice—disagreement attributed and not averaged, seat provenance (retained vs neutral) marked, cost visible, human left holding open questions at high stakes—established while agent-era norms are still wet cement. That good is achieved if the format and norm are absorbed elsewhere; Symposium-the-server does not have to win for the contribution to count.

What you are wrong about, in short: conflating project adoption with norm success; calling subscription CLI seats zero-marginal-cost; treating retained context as simply advocacy/sycophancy rather than informed-but-interested counsel that still needs labeling; under-weighting narrative and over-weighting technical cleverness if (c) is put first; and imagining a pre-release solo project can skip the public artifact (spec + real ledger + essay) and still set the missing standard by code alone.
